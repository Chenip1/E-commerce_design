# 图匠室 · GitHub Pages

从买家关心的品类信息出发，为零食、3C 数码、美妆和服饰设计不同的上新套图，也让卖家用已有商品资料快速制作节日大促图。

本仓库含图匠室工作台源码。GitHub Pages 构建运行在浏览器内，支持商品品类示例、制图编辑、导出、风格模板和本机草稿。云端保存、账号登录和模型生成可在[完整版](https://shangxin-workshop-yiping.shadyorbit13.chatgpt.site/)使用。

使用 Node.js 24 运行 `npm ci`、`npm run build:pages` 和 `npm run preview:pages`。静态输出位于 `dist-pages/`。GitHub Pages 的发布来源选择 GitHub Actions。
